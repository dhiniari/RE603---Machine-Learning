# Supervised Learning - Classification Hands-On

## Deskripsi
Project ini berisi implementasi beberapa algoritma **Supervised Learning untuk Classification** menggunakan Python di Jupyter Notebook.

Notebook utama:
- `Week_5_6_7_Supervised_Learning_Hands_On_Classification_All_tanpa_tuning.ipynb`

Materi di dalam notebook meliputi:
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Training Model
- Evaluation Model
- Perbandingan beberapa algoritma klasifikasi
- Contoh penggunaan parameter model
- Contoh penggunaan `GridSearchCV`

---

## Algoritma yang Digunakan
Beberapa algoritma classification yang digunakan dalam notebook ini:

1. K-Nearest Neighbors (KNN)
2. Naive Bayes
3. Decision Tree

---

## Struktur Pembelajaran
### 1. Exploratory Data Analysis (EDA)
Tahapan analisis data untuk memahami:
- Struktur dataset
- Distribusi data
- Missing value
- Statistik dasar
- Visualisasi data

### 2. Feature Engineering
Tahapan preprocessing data seperti:
- Pemilihan fitur
- Transformasi data
- Persiapan data sebelum training

### 3. Training Model
Melakukan training model classification menggunakan beberapa algoritma.

### 4. Evaluation
Evaluasi performa model menggunakan metrik classification.
